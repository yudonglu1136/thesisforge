# Home：已确认的三栏联动工作台（当前实现）

本地预览：http://127.0.0.1:5184/?view=home&asOf=2026-06-01&lang=en

## 选择纠正

此前把图片完成顺序误当成展示顺序，错误实现了大头像研究简报。用户确认的正确视觉是 `exec-82f085f7-6688-4bf4-84f2-fb3909ae6757.png`：左侧选投资人、中间选申报季度与持仓、右侧联动研究。以下旧简报记录只保留作为历史，不能作为当前方案验收。

## 本轮功能

- 左栏：三个主要投资人和全部 29 位经理菜单；实际头像、基金名、持仓日与披露日。
- 中栏：按真实 accession 选择申报，滚动查看普通股摘录；保留完整权重，不把期权当作普通股，不把摘录当作全部持仓。
- 右栏：所选股票的真实价格、已发布综合估值曲线、三项财务指标。仓位历史按同一证券 claim 展示最多 12 份历史申报，可切换股数、权重、申报市值。
- 原始申报对话框和 SEC 链接保留真实 accession；进入估值时带上经理、季度、股票和披露日。搜索可以选择已披露股票、经理，或明确进入独立公司研究。
- 手机使用投资人 / 持仓 / 研究三个步骤；点经理自动进入持仓，点股票进入研究。中文、英文均可用。
- 保留已保存研究和全部复核提醒；选股与浏览不写入投资决策。旧版简报组件已从首页移除。

## 数据边界

数据来自现有本地 PIT API，截止 2026-06-01，并非今日行情。切换申报季度不改变全局估值信息截止日，右栏明确不是经理买入时估值。已发布综合估值与可编辑 standalone FCFE 不是同一模型；本轮没有修改估值数学或重新承销假设。

ALAB 在此本地截止日的 API 返回 `no_pit_research_at_date`。这不是有图但没连上，而是没有可用 PIT 研究。缺失状态明确说明原因，不替代股票、不提供误导性刷新；持仓历史和申报入口仍可用。其他公司的历史覆盖率不因 UI 完成而被宣称补齐。

## 验证

- 208 项 Flutter 测试通过（76 项工作流），33 项后端工作流测试通过。
- 静态分析无问题；现有项目双语审计通过，新工作台双语由 widget 和浏览器检查补充验证；本地 web 构建通过。
- 回归涵盖：季度/股票/经理联动、精确 claim、旧请求串数据防护、PIT 日期、错误与缺失差别、重试、申报入口、无隐式保存、手机和桌面双语。
- 真实浏览器检查 Ackman → AMZN → Q4/Q1 仓位 → 对应估值，Gavin → ALAB 缺失模型但仓位可见，MSFT 手机中英文曲线。
- 图文逐轮对比和截图详见根目录 `design-qa.md` 与 `output/home-workbench-20260908/`。

本轮仅本地实现和验证，未提交 Git、未部署 AWS、未刷新付费源数据。真实用户理解度与转化率仍需验证。

# 历史记录：错误对应的研究简报（已被用户否定并替换）

本地预览：http://127.0.0.1:5184/?view=home&asOf=2026-06-01&lang=en

## 选中的方向

用户选择展示顺序中的第 2 张：深色研究简报。首页以真实人物、具体季度、持仓变化和估值曲线展示产品用途，而不是要求用户先理解功能目录。设计源为 `exec-07595ad2-6860-4230-b6dc-5b9976197be0.png`，完整路径和逐轮对照见根目录 `design-qa.md`。

## 已实现

1. 左侧重点呈现 Ackman 的 Q1 披露；经理菜单可切换实际目录。AMZN 展示相邻披露的股数、权重、持仓日和公开日，点击进入该经理 / 季度 / 股票的原有轨迹。
2. 右侧保留真实 MSFT 价格与综合估值历史，可切换 ISRG / NVDA，并直接进入可编辑估值。示例与大佬的买入估值明确分开；不改 DCF、综合估值或回测数学。
3. 下方用紧凑条带承接已保存研究；有待复核事项时仍完整呈现。搜索、日期、基本面入口和旧终端均保留。
4. 采用本地 DM Serif Display 标题、原品牌配色和实际头像 / Logo；为 Amazon、Uber 的白色透明 Logo 提供深色底。手机使用“大佬持仓 / 价格与估值”切换，两种语言均可操作。

数据并非来自设计图：使用本地 API 截至 2026-06-01 的真实发布摘录。AMZN 披露股数 9,607,824 → 11,451,981；这不等于已核验交易行为。缺失先前持仓不当作清仓、零持仓或首次买入；页面明确未核验公司行动影响。

## 当前验收

# 历史迭代：从空提醒页改为研究入口（已被上述第 2 版替代）

本地预览：http://127.0.0.1:5184/?view=home&asOf=2026-06-01&lang=en

## 为什么改

用户截图和本轮浏览器走查显示：空提醒占据主区，抽象标题没有解释产品用途，真正的研究入口被放到下方。此页面不是缺几张装饰图，而是没有让用户直接体验产品。

## 现在怎么用

1. **看大佬持仓：** 在 Bill Ackman、Warren Buffett、Gavin Baker 之间切换，看到已注明持仓日与披露日的普通股摘录及权重。点股票进入对应经理、披露季度和该股票的历史轨迹；全部经理目录仍可打开。
2. **检验价格与估值：** MSFT / ISRG / NVDA 提供真实、独立标注的估值示例。曲线沿用历史价格和已发布综合估值，不生成点、不修改金融模型。点击按钮直接进入可编辑的 FCFE 估值区；不会把示例归属于左侧选中的大佬。
3. **记录自己的判断：** 首页下方保留原有研究记录。空提醒只占一行；实际待复核记录仍优先显示，并能展开全部条目。首次访问不要求先配置提醒或创建组合。

手机将持仓与估值变成两个可直接切换的入口；桌面并列显示。现有深色品牌、导航、头像和股票 Logo 保留。

## 验收

- 前端全套：195 项通过，其中工作流 64 项，本轮新增 12 项。
- 后端工作流：33 项通过；本轮未修改后端或估值数学。
- 静态分析、最终本地构建、空白差异检查通过。
- 实际浏览器走通首页 → AMZN 历史轨迹、首页 → MSFT 可编辑估值，以及经理切换、估值示例切换和手机双语。
- 新增测试覆盖空搜索、无模型及重试、过期响应、截止日切换、期权排除、无隐式保存及完整提醒列表。
- 中文走查发现已保存动作未翻译，已修复并增加回归断言。

实际截图与逐轮视觉验收见 `../design-qa.md` 和 `output/home-redesign-20260908/`。本轮没有创建新的投资记录、刷新付费数据、提交 Git 或部署线上。理解度和转化提升尚未通过真实用户实验量化。
