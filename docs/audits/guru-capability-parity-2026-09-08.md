# Guru 功能迁移与工作流审计

日期：2026-09-08。范围：本地新版工作台、Discover，以及同一构建中的原版 Guru 终端。本轮仅审查、截图和写报告，未修改产品代码，未提交或部署。

## 结论

当前重构不是原版 Guru 的完整替代品。它做出了较清晰的“选经理 → 选披露股票 → 看估值”路径，却把原版的跨经理发现、申报变化分析、组合回测和贡献分析移出了主要工作流。

这是能力迁移缺口，不只是视觉问题，也不是大部分原代码被删除。保留旧终端入口并不等于在新产品中保留了易于发现、上下文连续的功能。用户不应知道哪个功能属于“旧版”。

用户选择的方案 2（三栏联动研究工作台）可以保留，但适合做深入研究视图，不能独占 Home、也不能代替整个 Guru 产品。应恢复两条平等入口：

1. 从股票发现：季度共同持仓 / 申报增减持 → 多经理证据 → 公司研究与估值。
2. 从经理发现：经理 → 完整披露与季度变化 / 仓位历史 / 模拟回测 / 贡献 → 公司研究与估值。

两条路径汇入同一个公司研究空间，再连接用户的估值、决定、监控和复盘。

## 建议的信息架构

### Home：展示有内容的研究起点，而不是强迫进入一个经理

- 首次/没有已保存研究：默认有季度 Guru 机会预览，包含共同持仓、申报增持、最新披露的真实内容。没有个人告警时，不让空告警卡占据主屏。
- 回访：继续研究、已保存规则触发的变化、关注经理的新披露；依然保留简洁的季度机会入口。
- Home 只摘取少量可行动条目，不重复一整套 Discover 排名和回测。

### Discover → Guru：把“季度全景”提升为主界面

- 一级选择：Quarterly overview / Managers。
- 全景内选择：Shared holdings / Reported adds / Reported trims。
- 顶部显示报告季度、信息截止日、已披露经理覆盖分母、证券范围。不能把不同截止日可见的不同季度直接混为同季度共识。
- 主体采用紧凑可排序股票表：股票 logo / 名称、经理数量、组合权重中位数、变化构成。金额作为辅助，而不是让基金规模主导排名。
- 选择股票后展开右侧详情：谁持有、谁增加、谁减少、报告与披露日期、股数/权重对照、估值摘要。大面积留给真实证据，不新增营销大卡片。
- 经理头像可点进该经理该季度的相关记录；估值入口可点进统一 Research。返回时保留季度、筛选、排序、股票和滚动位置。

### 经理详情：用方案 2 的风格承载原本完整工具

- 左侧经理选择可保留，头部概况紧凑但不能把重要字段截断到不可辨认。
- 主区保留 Holdings & Changes / Position history / Simulation / Contribution。
- 股票选中时右侧展开公司证据与估值；查看大图/回测时允许扩大主区。不要常驻占去三分之一宽度的无内容面板。
- 原有模块接入新的统一导航，不要求用户跳出到“旧终端”寻找关键功能。
- 手机改为列表 → 详情的清楚两步，提供明确返回；不硬塞桌面三栏。

## 实施顺序与质量门槛（建议，尚未执行）

1. **先确认能力清单与数据契约，再改视觉。** 将季度全景、经理页四个模块、完整持仓与估值返回路径设为重构不可丢失的验收项。
2. **复用原实现，建立统一上下文。** 每次跳转保留 asOf、reportQuarter、guruId、accession、精确证券/股权身份与来源。聚合基于该时点可见的完整披露，不从 topHoldings 摘录推导完整共识，不偷偷换成最新季度。
3. **先恢复全景与经理工具的主流程，再串联新研究。** 现有旧终端可在迁移期间继续可用，但“跳旧版”不算迁移完成。
4. **最后统一视觉。** 保留方案 2 的颜色、字体和联动逻辑；用真正有分析价值的表格、曲线和证据填充页面。增加文字标签替代重要的纯图标动作，解决截断与嵌套滚动。

下次验收应逐条实际走通，而非只检查 build / widget tests：

- 在 Guru 季度全景直接发现一只共持股票；一次选择看到完整经理证据，再一次操作打开该股估值；返回后原状态不丢失。
- 同一股切换共同持仓、申报增持、减持，核对经理分母与来源一致；缺数据明确显示，不默认成 0 或退出。
- 从任意经理选择历史季度，核对完整持仓/变化记录；从股票进入 Research，保留经理、披露与证券身份。
- 打开已就绪的组合回测，修改自由区间，检查组合与 SPY 同时归一、区间收益和回撤更新；10Y/All 失败仍保留最后已就绪曲线。不得放宽现有 90% 覆盖门槛来制造可见曲线。
- 从季度贡献定位相关股票，回到同一经理/季度；测试直接链接、刷新、返回与手机列表详情流程。
- 在 2026-06-01 截止日不能读到此后披露的 Q2；显式切换到 latest 后须持续显示不同时间口径。不能把旧版 latest 表直接嵌入历史 PIT 页。
- 代表性经理需覆盖集中型、大量持仓型、历史稀疏型；代表性证券需覆盖正常估值、无模型、无映射/不适用。非 13F 人物使用自己的披露语义。
- 宽屏与 1280×720 保证回测曲线和区间工具可见；手机不横向挤出主要操作。补测键盘、焦点、对比度、文字放大及图表可读替代信息。
