# Strategy step 4: Hedge — local delivery

## Product scope

Hedge is the **fourth card after CTA inside Strategies**, not a sixth navigation
tab. The temporary `view=hedge` entry redirects to Strategies. On wide desktops
the four steps occupy one row; narrower desktops use two rows, phones one column.

Choose No hedge, Protective Put, Put Spread, or Collar; set stock-sleeve coverage,
an available expiry, portfolio capital, assumed equity beta and assumed CTA return.
One run returns the existing historical strategy result plus a separately labeled,
dated allocation stress experiment. Save rules stores the hedge settings with the
same private, append-only strategy record. No broker order endpoints exist.

This is **not a completed rolling options backtest**. Its arithmetic uses configured
stock/CTA allocation, not realized Guru holdings, fitted beta, or valuation-filter
cash. Historical curves remain untouched and exclude options. Current observations
must not be inserted into past rebalance dates. A baseline failure is retained even
when a separate allocation scenario can calculate.

## Calculation contract

- Equity target = portfolio capital × (1 − CTA weight).
- Contracts = floor(equity target × requested coverage / (QQQ close × 100)).
- Actual coverage is computed from those whole contracts, not the target slider.
- Nearest available strikes: put ≈95%, lower put ≈85%, call ≈105% of QQQ close.
- Each long leg is marked at close × 1.05; each short at close × 0.95. This is an
  adverse-fill assumption, not a spread measured from the market.
- Opening commission is $0.65 per contract **per leg**.
- Base expiry P&L = equity target × max(−1, assumed beta × QQQ return)
  + CTA target × assumed CTA return. Cash from the valuation filter is not modeled.
- Overlay P&L = sum(signed intrinsic value × contracts × 100) − net hedge debit.
- Combined P&L = base + overlay. Net debit requires additional capital and is not
  silently taken from or added twice to the historical portfolio NAV.
- Put-spread protection stops increasing below the short-put strike.
- Guru stocks **do not cover a short QQQ call**. A proxy collar can create unlimited
  losses from basis mismatch; no hard portfolio floor or finite maximum loss is claimed.
- No early assignment, dividend, tax, margin, liquidation or rolling execution model.
