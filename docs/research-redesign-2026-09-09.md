# Research 工作台精细化改版

日期：2026-09-09。范围：现有私有本地预览；未部署、未推送 GitHub、未修改生产数据。

## 产品设计

沿用用户选定的 Graphite 方案 2：既有字体、深灰底、薄边界、薄荷绿操作、真实公司 Logo 与经理头像。重新组织现有能力，不替换估值引擎。

- 概览：明确公司、财报公开日、研究截止日、币种；价格/平台综合估值/模型价差；最新财务变化；下一步操作。
- 曲线：1Y / 3Y / 5Y / All，双端时间选区；报告期检查器展示当期估值、可比前期变化、收入同比和 TTM FCF 率。切换检查报告不会改变研究截止日或已保存情景。
- 财务与来源：保留原指标对照、历史分位、持有人披露细节、关联经理选择、来源与公式。将管理层摘录从原始 JSON 中提到可读区域，保留原文、发言者、时间和出处；展开可读全部摘录。
- 反例：根据已有指标提示现金转化率下降/持续性核查，不编造评级、同行数据、经营 KPI 或投资结论。
- 估值：平台综合估值与独立 DCF 部分分开呈现。支持的公司保留五年现金流、Bear/Base/Bull、Ke/g、反向估值、敏感性、归属确认、保存版本与决策。
- 只读模型：明确能力边界，提供检查方法和保存观察；决策页不再要求保存一个不存在的可编辑情景。

## 修复的交互问题

1. Research 入口只有 `candidate=NVDA` 时可以准确加载 NVDA；显式 `valuation` 优先，其他页面不误用候选参数。
2. 当前候选已有研究数据、但 Research 尚未加载时，导航直接承接候选公司与原返回上下文。
3. API 返回不同股票时停止呈现，不替换选中股票。输入请求使用规范化后的 ticker。
4. 切换公司保留截止日，未保存修改仍需确认；切换到另一家公司不再标成原候选公司的证据来源。
5. 手机端将 Valuation 放到前两个标签内；水平可滚动导航保留其他入口。
6. 图表时间滑块使用归一化值和日期语义，避免毫秒大数影响交互；报告选择键包含财报期及披露日。
7. “全部持有人与披露详情”有专用滚动锚点，进入对应披露区域。

## 金融与数据边界

- 使用现有本地 PIT 数据/API，未抓取新指引、刷新付费数据、修改估值数字或公式。
- 模型变化仅在公式和模型版本一致且前值为正时计算；这不是单项因果归因。
- 模型价差只在报价币种与模型币种明确一致时显示；缺失值为破折号，不作为零。
- 价格历史明确标注存储样本数量和起止日期，不承诺连续完整日线。
- 历史图是使用存储模型版本重建的 PIT 回放，不冒充当时发布的建议；管理层摘录不自动代表已采纳的模型输入。
- 13F 为有限摘录/滞后披露；原始股数变化不是经公司行动校验的交易结论。
- 保存观察是已有独立观察工作流，冻结当前股票/日期/平台模型，不新增情景、仓位或投资决策。
